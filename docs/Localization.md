# Language and regional input

HermitSDR uses English by default. To choose another language, go to
**System Settings → General → Language & Region → Applications**, add
HermitSDR, and choose a language. Reopen the app to apply the change.

Translations cover the Radio, Transmit, Decode, Log and Station menu titles,
key commands, the radio connection sheet’s main labels, and the Set Frequency
dialog. Other controls, detailed help and operator documentation still use
English.

- Europe and Latin America include Czech, Danish, Dutch, Finnish, French,
  German, Greek, Hungarian, Italian, Norwegian Bokmål, Polish, Portuguese
  for Brazil and Portugal, Romanian, Russian, Spanish including Latin
  America, Swedish, Turkish and Ukrainian.
- South Asia includes Bengali, Gujarati, Hindi, Kannada, Malayalam,
  Marathi, Nepali, Punjabi in Gurmukhi and Shahmukhi, Sinhala, Tamil,
  Telugu and Urdu.
- East and Southeast Asia include Simplified and Traditional Chinese,
  Indonesian, Japanese, Korean, Thai and Vietnamese.

**Radio → Set Frequency** and the inline dial accept your regional decimal
separator, a decimal point or comma, full-width characters and Unicode
decimal digits. For example, `7.074125`, `7,074125`, `７．０７４１２５`,
`७.०७४१२५` and `৭.০৭৪১২৫` all enter 7.074125 MHz. Enter the value
without digit grouping. Regional number entry follows macOS regional
settings and works even when the app language is English.
